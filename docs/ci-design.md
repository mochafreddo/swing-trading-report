# CI 설계

2026-10-04 CI 검토에서 확정한 결정과 로컬 구현을 기록한다. GitHub Actions에서의 실행과 필수 병합 조건 적용은 별도 단계다.

## 확정한 범위

- 기본 CI는 인증정보와 외부 API 없이 코드 회귀를 검사한다. 기존 테스트, 오류 주입 검사, 프로브 자체 검증을 사용한다. 실제 API 검증은 별도 실행으로 둔다.
- Python 지원 범위를 3.14 하나로 좁힌다. 실행 안내도 같은 지원 범위를 사용한다.
- 확정한 검증은 필수 병합 조건으로 삼는다. GitHub 설정 변경은 워크플로 검증 후 별도로 진행한다.
- macOS와 Ubuntu 모두 Python 3.14를 검사한다.
- 모든 PR과 `main` push에서 자동 실행하고 수동 실행도 지원한다. 문서도 계약·재현 검사에 영향을 주므로 경로 필터는 두지 않는다. `main`은 설계 시점의 로컬 원격 추적 정보 기준이며, 적용 전에 원격 기본 브랜치를 확인한다.
- 테스트와 두 프로브 자체 검증은 모든 환경에서 실행한다. 오류 주입 전체 검사는 Ubuntu의 Python 3.14에서 매번 실행한다.
- 로컬과 CI의 Python 버전 관리 및 검증 명령을 mise로 통일한다. 기존 Python 검증 로직은 유지하고 mise 작업에서 호출한다.
- 같은 PR에 새 변경이 올라오면 이전 CI 실행은 취소한다. 각 작업의 제한 시간은 우선 15분으로 두고 첫 CI 실행 결과에 따라 조정한다. 15분은 실제 CI 소요 시간의 측정값이 아니다.
- CI에는 체크아웃에 필요한 읽기 권한만 부여하고 인증정보를 전달하지 않는다.
- actionlint와 ShellCheck를 연동해 워크플로를 검사한다. 정적 검사는 Ubuntu에서 한 번 실행한다.
- Ruff는 Python 3.14를 대상으로 `E4,E7,E9,F,I,B,UP,SIM,RUF` 규칙과 `ruff format --check`를 적용한다. 위반은 CI 실패로 처리하고, 예외는 개별 사유를 검토해 최소한으로 허용한다.
- 린트와 포매터 도입에 필요한 기존 코드 정리를 구현 범위에 포함한다. 실행 동작을 유지하며 테스트가 사용하는 `single_run.digest`의 재노출과 오류 주입 검사의 변형 대상을 보존한다.

## 구현 전 검토 근거

현재 체크아웃의 추적 파일과 파일시스템에서 CI 설정을 찾지 못했다. GitHub Actions 활성화 상태와 병합 보호 설정은 조회하지 않았다.

로컬 Python 3.14.7에서 `python3 -B -m unittest discover`의 테스트 89개가 통과했다. `python3 -B check_negative_controls.py`의 오류 주입 94개는 각각 정상 구현의 종료 코드 0과 변형 구현의 종료 코드 1 및 단언 실패를 확인했다. 두 프로브의 `--self-check`도 통과했다. 이 결과는 다른 Python 버전이나 운영체제, 실제 API 연동의 검증을 의미하지 않는다.

기존 검증 명령은 [한 종목 실행 안내](single-run.md)와 [전체 종목군 실행 안내](universe-run.md)에 있다. 별도 검증 진입점은 `probe_alpaca_trades.py --self-check`와 `probe_earnings_sources.py --self-check`다.

추가 도구 검토에서는 설치된 Ruff 0.16.10으로 Python 3.14 대상의 `E4,E7,E9,F,I,B,UP,SIM,RUF` 규칙을 실행했다. 진단은 10개 파일에서 179개였으며, 그중 126개는 루프 변수의 함수 캡처를 지적하는 `B023`이었다. 진단 수는 확인된 결함 수와 다르다. 같은 대상으로 포매터 검사에서는 11개 파일의 변경이 필요하다고 보고했다. 두 검사는 파일을 수정하지 않았다.

오류 주입 검사는 소스의 정확한 문자열을 찾아 변형하므로, 포맷을 바꾸면 변형 대상도 점검해야 한다. 포매터 적용을 포함한다면 기존 테스트와 오류 주입 검사를 모두 다시 실행해 확인한다.

## 도구 버전 정책

Python은 `3.14`로 지정해 패치 버전을 고정하지 않는다. mise 자체와 정적 검사 도구는 정확한 버전, GitHub Actions는 커밋 SHA로 고정한다. 실제 Python 패치 버전은 검증 로그에 남긴다. Python의 부분 버전 지정은 매번 자동 갱신을 뜻하지 않으므로 설치 상태에 따라 로컬과 CI의 패치 버전은 달라질 수 있다. 버전의 기준은 [mise 설정](../mise.toml)과 [워크플로](../.github/workflows/ci.yml)이다.

## 구현과 검증 범위

`mise.toml`에 Python·검사 도구와 공통 검증 작업을 선언하고, Ruff 설정 및 GitHub Actions 워크플로를 추가한다. 실행 안내의 지원 버전과 검증 명령도 갱신한다. 새 런타임 의존성은 추가하지 않는다.

코드 정리 후 Ruff 린트·포매터 검사, actionlint·ShellCheck 검사, 전체 테스트, 두 프로브 자체 검증, 오류 주입 전체 검사를 실행한다. 오류 주입 검사는 정상 구현의 성공과 변형 구현의 단언 실패를 모두 확인한다. 로컬 검증은 실행한 운영체제와 도구 버전 범위에서 보고하며, GitHub의 macOS·Ubuntu 실행 결과와 구분한다.

도구 설치가 필요하면 설치 전에 확인한다. 원격 게시와 GitHub의 필수 병합 조건 적용은 로컬 구현·검증 후 별도로 진행한다.

## 로컬 검증

저장소 루트에서 다음 명령으로 설정을 신뢰하고 도구를 준비한 뒤 전체 검증을 실행한다.

```sh
mise trust
mise install
mise run check
```

`mise run test`는 전체 unittest와 두 프로브 자체 검증을 순서대로 실행한다. `mise run negative-controls`는 격리된 임시 복사본의 정상·변형 구현을 비교한다. `mise run lint`는 Ruff 린트·포맷 검사와 ShellCheck를 연동한 actionlint 검사를 실행한다. `mise run check`는 세 작업을 모두 실행하며 하나라도 실패하면 실패한다.

Ruff는 실행·테스트 코드의 Python 파일을 검사한다. 보고서의 수학 기호 `×`와 `−`는 의도한 출력이므로 허용하며, 기존 보고서의 표현을 바꾸지 않는다. 다른 규칙을 일괄 제외하거나 기존 경고를 기준선으로 숨기지 않는다. 린트와 구문 검사는 정적 타입 검사를 대신하지 않는다.

## GitHub 적용

워크플로는 정적 검사와 운영체제별 테스트의 결과를 `CI result` 검사로 모은다. 두 작업이 모두 성공해야 이 검사가 성공하며 실패·취소·생략된 작업을 성공으로 처리하지 않는다. 워크플로 게시 후 macOS·Ubuntu 실행을 확인하고 `CI result`를 필수 병합 조건으로 설정한다. 저장소의 Actions 활성화 상태와 병합 보호 설정은 이 문서의 로컬 구현으로 변경되지 않는다.

외부 시세·기업 자료 서비스의 인증정보는 CI에 등록하거나 테스트에 전달하지 않는다. 체크아웃과 도구 설치 액션에는 GitHub가 제공하는 읽기 권한의 기본 토큰만 사용한다.

## 로컬 구현 검증

2026-10-04 macOS의 Python 3.14.7에서 전체 테스트 89개와 두 프로브 자체 검증이 통과했다. 단일 테스트 파일별 검사와 Python 구문 검사도 통과했다. 오류 주입 94개는 각각 정상 구현의 종료 코드 0, 변형 구현의 종료 코드 1과 단언 실패를 확인했고, 기존 검사 이름·대상 파일·테스트 연결을 보존했다.

Ruff 린트와 11개 Python 파일의 포맷 검사, ShellCheck를 연동한 actionlint 검사가 통과했다. actionlint는 같은 절차에서 정상 워크플로를 통과시키고, 존재하지 않는 행렬 변수를 넣은 변형 워크플로를 실패시켰다. `CI result`의 실제 셸 명령은 두 선행 작업의 성공·실패·취소·생략 상태 조합 16개 중 둘 다 성공한 경우에만 성공했다.

`mise run test`와 `mise run lint`는 자동 설치를 끄고 기존 설치 도구를 재사용해 검증했다. 새 환경에서 도구를 다운로드하는 설치 과정과 GitHub Actions 실행은 검증하지 않았다. 정적 타입 검사 도구가 설치되어 있지 않아 타입 검사는 생략했으며, Ruff와 구문 검사 결과로 이를 대체하지 않는다.
