# #233 자료 마감과 준비·전달 시각 검증

2026-10-10에 합의한 다섯 정책을 구현한 증분 검증 기록이다. 기준 커밋은 `b12f6b0e1f9be32f92f1aad36038a5fe8d67563d`이며, [#233](https://github.com/mochafreddo/swing-trading-report/issues/233) 전체 완료를 입증하는 기록은 아니다.

## 구현 범위

전체 실행은 시간대가 있는 자료 마감 시각을 명시적으로 받으며 검증된 개장 60분 전 준비 시한보다 늦은 값을 거부한다. 마감 이후에는 새 자료 요청을 중단하고, 늦게 반환된 응답은 진단 근거로만 보존한다. 앞서 검증한 결과는 유지하며 미완료 종목은 보류한다. 오프라인 재현은 당시 요청 순서와 마감 판정을 따른다.

보고서와 실행 기록을 쓴 뒤 준비 완료 시각을 `readiness.json`에 저장한다. 수집 종료, 준비 완료, 실제 발행을 구분하고 각 산출물의 해시를 연결한다. 측정된 준비 소요 시간은 보고서·실행 기록 작성까지이며 준비 기록 자체의 작성과 전송 시간은 포함하지 않는다. 실제 운영 마감의 여유 시간은 측정 후 정한다.

전체 보고서 전송은 달력·보고일·복구 시한을 확인하고 HTTP 요청 직전에 시간을 다시 확인한다. 전송 중 늦게 발행된 경우에는 확인된 전송을 보존하고 지연 캡션을 한 번 수정한다. 수정 결과가 불명확하면 자동 수정 재시도나 원문 재전송을 하지 않는다. 예약 실행과 누락 안내 자동화는 포함하지 않는다.

IR 검토 목록은 원래 전체 탐색에서 가격 조건을 통과했으나 출처가 없거나 검증되지 않은 기업을 추린다. 원래 실행의 보류 결과를 소급 변경하지 않는다. 별도 [거래대금 대안 조사](issue-233-turnover-alternatives.md)는 무료 경로의 계약과 독립 달러 금액 대조를 확인하기 전 대량 조회를 시작하지 않는 기준을 기록한다. 현재 조사로 모든 무료 경로가 불가능하다고 판단하지 않는다.

## 검증 경계와 결과

사용자가 승인한 두 공개 경계를 사용했다. 첫째는 전체 실행에서 보고서·실행 기록·오프라인 재현까지이며, 둘째는 저장된 보고서에서 텔레그램 전송 기록까지다. 새 회귀 검사는 구현 전 실패를 확인한 뒤 통과시켰다.

- `MISE_AUTO_INSTALL=0 mise run test`: 152개 테스트와 Alpaca·IR 프로브 자체 검증 통과. 첫 전체 실행은 기존 인증 오류 CLI 테스트가 새 필수 마감 인자를 전달하지 않아 실패했으며, 테스트 호출을 수정한 뒤 최종 전체 실행이 통과했다.
- `MISE_AUTO_INSTALL=0 mise run lint`: Ruff, 포맷, actionlint 통과.
- `mutation-probe.py`: 새 로직 9개 변이에 대해 정상 사본 통과와 변이 사본 실패를 같은 환경에서 확인했다. 요청 전·응답 후 마감, 인증 요청 간 대기 후 HTTP 차단, 준비 기록 시각 일관성, 준비와 발행의 결합, 달력 미확보, IR 검토 범위, 지연 캡션 수정, 저장 지연 이후 복구 시한 재검사를 검증했다. 한 초기 변이는 중복 시한 가드가 동작해 살아남았고, 달력 미확보 가드를 검사하는 변이로 범위를 고쳐 최종 9개를 확인했다. 포맷 변경으로 앵커가 사라진 초기 호출은 유효한 검사로 세지 않았다.
- `MISE_AUTO_INSTALL=0 mise run negative-controls`: 기존 121개 오류 주입 검사에서 정상 사본 통과와 변이 사본의 단언 실패를 확인했다.

변이 도구는 실행 기록·인증 자료를 제외하고 Python 소스와 도메인 문서만 복사한 소유자 전용 임시 디렉터리에서 실행했다. 원본 소스의 해시와 검사 사본을 대조했다. 실제 시세·공급자 계정·텔레그램 전송은 사용하지 않았다.

## 리뷰와 한계

Standards와 Spec을 독립적인 읽기 전용 reviewer에 맡겼다. 달력 미확보, 전송 중 시한 경과, 저장 후 요청 전 시한 경과 문제를 수정했으며 최종 소스 리뷰에 남은 지적 사항은 없다. reviewer의 테스트 실행 결과로 간주하지 않는다. 역할 설정에 따라 호출했으나 도구 응답에서 실제 모델·추론 강도·권한 적용을 확인할 수 없어 해당 실행 설정은 `dispatched-unverified`로 기록한다.

정적 타입 검사 도구인 mypy·pyright가 설치되어 있지 않아 타입 검사를 생략했다. Ruff 통과는 타입 검사 통과를 뜻하지 않는다. 공급자의 과거 SIP 거래 식별자·정정·조건 의미, 같은 범위의 독립 거래대금 금액 대조, 실제 IR 정확성, 후보가 선정되는 실제 전체 실행, 실제 준비·전송 소요 시간과 개인 채팅 수신은 이번 합성 검사로 입증하지 않았다. 이 근거가 확보될 때까지 #233은 미완료 상태다.
