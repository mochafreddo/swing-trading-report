# 한 종목 평가 계약

이 문서는 [#232](https://github.com/mochafreddo/swing-trading-report/issues/232)의 계산 구현·변경 전에 고정한 데이터·계산 계약이다. 검증 대상은 마이크론(MU) 한 종목이며 전체 종목군 탐색, AI 설명, 텔레그램 전송, 첫 마일스톤 완료를 의미하지 않는다. Python 3.11 이상과 표준 라이브러리만 사용한다.

## 수집과 검증

| 자료 | 자동 수집 경로 | 판정에 필요한 확인 |
| --- | --- | --- |
| 거래 가능 여부·거래소·보통주 | 토스 `GET /api/v1/stocks/all?market=NASDAQ&status=ACTIVE&commonShare=true`, `GET /api/v1/stocks?symbols=MU` | 전체 목록 내 MU 존재, 상세 응답의 NASDAQ·보통주·주식 유형·ACTIVE·USD 일치 |
| 발행주식수 | 토스 종목 상세 `sharesOutstanding` | 양수인 주식 수. 조회 시각을 보존한다. |
| 정규장 일봉 가격·거래량 | KIS `dailyprice`, `EXCD=NAS`, `GUBN=0`, `MODP=0`; Yahoo MU 일봉 `includePrePost=false`, 기업행사 포함 | 거래일·USD·종목·시간대·일봉 주기를 검증한다. KIS 원주가 OHLC를 Yahoo 일봉과 센트 반올림 기준으로 대조하고, 거래량은 Yahoo 일봉의 동일 계열을 사용한다. |
| 거래대금 하한 | KIS `inquire-time-itemchartprice`, `EXCD=NAS`, `NMIN=30`, `PINC=1`, 연속 조회 | 최근 20거래일의 달력상 정규장 안에 완전히 들어가는 30분봉의 실제 `eamt`를 합산한다. 무료 Nasdaq TotalView의 부분집계로 전시장 거래대금의 하한이다. |
| 거래일과 정규장 시간 | 토스 `GET /api/v1/market-calendar/US?date=...` | 전일로 이어지는 50개 정규장과 보고일 포함 다음 5개 정규장을 구성한다. 휴일을 평일로 대체하지 않는다. |
| 확정 다음 실적 발표일 | Micron 공식 뉴스룸에서 실적 발표 예고 링크를 찾고 기업 IR의 `NewsArticle`을 수집 | MU 기업 공지의 제목에서 결과 발표일을 추출하고 발행 시각·출처·조회 시각을 보존한다. 예상·잠정·취소·연기 표현이 있거나 확정 근거가 없으면 보류한다. |

시가총액은 조회한 발행주식수 × 전일 정규장 종가(USD)로 계산한다. 이는 전일 종가 기준 계산값이며 제공자의 실시간 시가총액과 구분한다.

가격 검증에서는 Yahoo의 `quote` 계열을 사용하며 배당까지 소급 반영한 `adjclose`를 사용하지 않는다. 현금배당에 따른 가격 갭은 그대로 ATR에 포함한다. Yahoo의 기업행사 응답에 평가 구간 시작일부터 보고 당일까지 분할이 있으면 가격·거래량 조정 관계를 추가 검증할 때까지 보류한다. 배당 때문에 KIS `MODP=0`과 `1`이 다른 것만으로 보류하지 않는다. KIS 원주가와 Yahoo 가격의 센트 단위 대조, Yahoo의 정규장 최종 가격·시각과 마지막 일봉의 일치, 토스 달력과 각 일봉의 현지 개장 시각 일치를 확인한다. 가격은 전일까지의 50일만 허용하지만 기업행사 조회는 보고일 다음날 자정까지 요청해 보고 당일 분할도 확인한다. 이는 조회 시점에 공개된 기업행사 응답의 검증이며 공급자가 아직 반영하지 않은 행사의 부재를 보장하지 않는다. 공급자의 가격 정정이나 대조 불일치는 보류한다. 센트 비교는 Yahoo의 가격 표시 정밀도와 이진 소수 표현 차이를 흡수하며 계산 자체에는 KIS 가격 정밀도를 유지한다.

거래대금은 세션 범위가 불명확한 KIS 일봉 `tamt` 대신 현지 시각이 있는 분봉의 `eamt`를 사용한다. 각 분봉은 `[현지 시각, 현지 시각 + 30분)`으로 취급하며 달력상 정규장 밖의 봉과 마감 이후 봉은 제외한다. 날짜·시각 중복, 진행하지 않는 페이지, 최근 20거래일 중 누락된 봉, 현지·한국 시각 불일치, OHLC 역전, 거래량·금액 단위 불일치는 보류한다. 해당 구간을 최대 12페이지 안에 확보하지 못해도 보류한다. 거래대금을 종가 × 거래량으로 추정하거나 다른 시장의 거래량으로 확대하지 않는다.

분봉 금액은 정수 USD로 제공된다. `저가 × 체결량 - 1 ≤ 체결대금 ≤ 고가 × 체결량 + 1`로 정수 금액의 일관성을 확인하고, 반올림으로 하한을 과대평가하지 않도록 각 봉에서 1 USD를 차감한 양의 금액만 합산한다. 정규장 일부 거래소의 실제 거래는 전체 정규장 거래의 부분집합이므로, 최근 20거래일의 이 합계 평균이 5,000만 USD 이상이면 원래 유동성 기준 통과를 입증한다. 하한이 기준 미만이면 전체 금액도 미만이라고 결론낼 수 없으므로 제외가 아닌 보류다. 하한을 정확한 전시장 평균이나 후속 후보 간 동순위 비교값으로 사용하지 않는다. 이 단건은 기존 금액 문턱을 바꾸지 않고 통과의 충분조건만 확인한다.

실제 자료와 합성 자료는 같은 검증·계산 경로를 사용한다. 합성 여부는 기록과 보고서의 자료 구분에만 사용하며 검증을 우회하지 않는다. 필수 자료의 검증 근거가 없으면 후보와 가격 계획을 제시하지 않는다.

실행은 보고일의 미국 동부시간 자정 이후 정규장 개장 전에 수집한 자료를 사용한다. 전일 정규장이 끝났는지 확인하며, 이전 날짜를 지정해 현재의 종목 정보나 IR 자료로 과거 판단을 꾸미지 않는다. 과거 결과는 보존된 실행 기록으로만 재현한다. 자료의 확인 시각과 제공자가 명시한 시각을 구분한다.

## 계산 규칙 v2

`T`는 보고일 직전 정규장 거래일이다. 수집 일봉의 정확히 마지막 50개 거래일을 날짜 오름차순으로 사용한다. 가격은 50거래일, 거래량은 T와 직전 20거래일, 거래대금은 T를 포함한 20거래일이 계산에 필요하다. 해당 입력 구간의 거래일 누락·중복·순서 불일치, 미래 봉, 0 이하 값, 비유한 수치, OHLC 역전은 보류한다. 계산에 사용하지 않는 과거 거래대금의 이상만으로 평가를 보류하지 않는다. 제공자의 단위·세션 미검증은 구간과 별개로 보류 사유다.

- 규모: 위 시가총액이 10,000,000,000 USD 이상이다.
- 유동성: T를 포함한 마지막 20거래일의 거래대금 평균이 50,000,000 USD 이상이다. 위 부분집계 하한이 문턱 이상일 때만 통과가 확인된다.
- 돌파: T 종가가 T를 제외한 직전 20거래일의 최고가보다 크다.
- 거래량: T 거래량이 T를 제외한 직전 20거래일 평균의 1.5배 이상이다.
- 이동평균: T 종가가 T를 포함한 50거래일 종가의 단순평균보다 크다.
- ATR(14): 첫 봉은 전일 종가용으로만 사용한다. 두 번째~열다섯 번째 봉의 14개 TR 산술평균을 초기값으로 하고 이후 봉마다 `(직전 ATR × 13 + TR) / 14`를 적용한다. TR은 `max(고가−저가, abs(고가−직전 종가), abs(저가−직전 종가))`다. 정확히 50봉으로 초기값과 재귀 횟수를 고정한다.
- 실적 제외: 보고일 포함 앞으로 5개 정규장 거래일의 마지막 날짜까지 다음 확정 발표일이 있으면 제외한다. 중간 휴일·주말에 발표하는 경우도 날짜 구간에 포함한다. 장전·장후 시각은 제외 여부에 영향을 주지 않는다. 다음 확정 발표일이 없거나 예상만 있으면 보류한다.
- 순위: 이 티켓은 한 종목이므로 선정된 경우만 1위다. 후속 전체 탐색에서는 거래량 증가 배율 내림차순, 평균 거래대금 내림차순, 티커 오름차순으로 정렬한다.

계산에는 `Decimal` 28자리 정밀도를 사용한다. 중간 값은 표시용으로 반올림하지 않는다. 보고서의 가격 표시는 소수 둘째 자리에서 반올림하며 원래 계산값과 산식은 기록에 남긴다.

선정된 종목만 진입 검토 구간 `[T 종가, T 종가 + 0.5ATR]`, 손실 제한 기준 `돌파 기준선 − ATR`, 예시 `1R = T 종가 − 손실 제한 기준`, 예시 이익 실현 기준 `T 종가 + 2R`을 표시한다. ATR·손실 제한 기준·1R이 양수가 아니면 보류한다. 진입 계획은 보고일 정규장 하루에만 유효하며 실제 진입가가 달라지면 다시 계산한다. 실제 체결이나 최대 손실을 보장하지 않는다.

필수 자료의 미검증은 `held`/평가 불가, 검증된 자료의 조건 탈락은 `excluded`/조건 충족 후보 없음, 모든 조건 통과는 `selected`로 기록한다. 필수 자료 누락을 확인한 경우 조건 탈락보다 보류가 우선한다. 실적 날짜가 확정되었더라도 시세가 미검증이면 후보가 될 수 없다.

## 기록과 검증 경계

단건 실행은 새 디렉터리에 `record.json`과 `report.md`를 작성한다. 기록에는 형식·규칙 버전, 코드 해시, 규칙 본문, 실제 자료/검증 사례 구분, 요청 URL과 확인 시각, 수집한 공개 응답, 수집 실패 분류, 정규화 자료와 판정·계산 결과를 보존한다. 인증 헤더·환경변수·오류 응답 본문은 기록하지 않는다. 기존 실행 디렉터리는 덮어쓰지 않는다.

재현은 네트워크 없이 보존된 공개 응답을 다시 정규화·계산하여 결과가 일치하는지 확인한다. 코드·규칙 버전이 다르거나 입력 무결성이 달라지면 일치를 주장하지 않는다. 합성 응답을 쓰는 검증은 최종 보고서와 기록을 읽는 단건 실행 경계에서 수행하고 실제 연동 증거와 구분한다. 조건 경계, 가격 계획, 잘못된 시세, 실적 미확인·예상·제외 기간·장전·장후, 휴장일, 재현 및 실패 결과를 확인한다.
