# 한 종목 평가 계약

이 문서는 [#232](https://github.com/mochafreddo/swing-trading-report/issues/232)의 계산 구현 전에 고정한 데이터·계산 계약이다. 검증 대상은 마이크론(MU) 한 종목이며 전체 종목군 탐색, AI 설명, 텔레그램 전송, 첫 마일스톤 완료를 의미하지 않는다. Python 3.11 이상과 표준 라이브러리만 사용한다.

## 수집과 검증

| 자료 | 자동 수집 경로 | 판정에 필요한 확인 |
| --- | --- | --- |
| 거래 가능 여부·거래소·보통주 | 토스 `GET /api/v1/stocks/all?market=NASDAQ&status=ACTIVE&commonShare=true`, `GET /api/v1/stocks?symbols=MU` | 전체 목록 내 MU 존재, 상세 응답의 NASDAQ·보통주·주식 유형·ACTIVE·USD 일치 |
| 발행주식수 | 토스 종목 상세 `sharesOutstanding` | 양수인 주식 수. 조회 시각을 보존한다. |
| 일봉·거래대금 | KIS `dailyprice`, `EXCD=NAS`, `GUBN=0`, `BYMD=전일`, `MODP=0`과 `1` | 미국 현지 거래일 `xymd`, USD OHLC, 주 단위 `tvol`, USD `tamt`. 원주가·수정주가 응답을 모두 보존한다. |
| 거래일과 정규장 시간 | 토스 `GET /api/v1/market-calendar/US?date=...` | 전일로 이어지는 50개 정규장과 보고일 포함 다음 5개 정규장을 구성한다. 휴일을 평일로 대체하지 않는다. |
| 확정 다음 실적 발표일 | Micron 공식 뉴스룸에서 실적 발표 예고 링크를 찾고 기업 IR의 `NewsArticle`을 수집 | MU 기업 공지의 제목에서 결과 발표일을 추출하고 발행 시각·출처·조회 시각을 보존한다. 예상·잠정·취소·연기 표현이 있거나 확정 근거가 없으면 보류한다. |

시가총액은 조회한 발행주식수 × 전일 정규장 종가(USD)로 계산한다. 이는 전일 종가 기준 계산값이며 제공자의 실시간 시가총액과 구분한다. 거래대금은 `tamt`를 사용하며 종가 × 거래량으로 대체하지 않는다. 거래대금 ÷ 거래량이 해당 일봉 저가~고가 범위에 있는지 확인한다. 이 검사는 금액 단위의 수치적 일관성을 확인할 뿐 정규장 세션을 입증하지 않는다.

실제 응답의 단위·세션과 수정주가 특성은 문서의 필드 존재와 별도로 확인한다. 특히 현재 읽은 KIS 예제는 정규장 전용 집계 여부를 명시하지 않는다. 이 확인이 끝나기 전 실제 수집 결과는 보류하고 가격 계획을 제시하지 않는다. 수집 코드의 실제 자료 경로에 검증 완료를 임의 입력하는 옵션은 두지 않는다.

최소 구현에서는 50거래일의 원주가·수정주가 OHLC와 거래량이 모두 같은 구간만 평가한다. 차이가 있으면 기업행사에 따른 가격·거래량·거래대금 조정 관계가 미검증된 것으로 보류한다. 수정 이력을 섞거나 누락 봉을 채우지 않는다. 후속 구현에서 기업행사별 조정 규칙과 검증을 추가하면 이 제한을 해제할 수 있다.

실행은 보고일의 미국 동부시간 자정 이후 정규장 개장 전에 수집한 자료를 사용한다. 전일 정규장이 끝났는지 확인하며, 이전 날짜를 지정해 현재의 종목 정보나 IR 자료로 과거 판단을 꾸미지 않는다. 과거 결과는 보존된 실행 기록으로만 재현한다. 자료의 확인 시각과 제공자가 명시한 시각을 구분한다.

## 계산 규칙 v1

`T`는 보고일 직전 정규장 거래일이다. 수집 일봉의 정확히 마지막 50개 거래일을 날짜 오름차순으로 사용한다. 거래일 누락·중복·순서 불일치, 미래 봉, 0 이하 가격·거래량·거래대금, 비유한 수치, OHLC 역전은 보류한다.

- 규모: 위 시가총액이 10,000,000,000 USD 이상이다.
- 유동성: T를 포함한 마지막 20거래일의 거래대금 평균이 50,000,000 USD 이상이다.
- 돌파: T 종가가 T를 제외한 직전 20거래일의 최고가보다 크다.
- 거래량: T 거래량이 T를 제외한 직전 20거래일 평균의 1.5배 이상이다.
- 이동평균: T 종가가 T를 포함한 50거래일 종가의 단순평균보다 크다.
- ATR(14): 첫 봉은 전일 종가용으로만 사용한다. 두 번째~열다섯 번째 봉의 14개 TR 산술평균을 초기값으로 하고 이후 봉마다 `(직전 ATR × 13 + TR) / 14`를 적용한다. TR은 `max(고가−저가, abs(고가−직전 종가), abs(저가−직전 종가))`다. 정확히 50봉으로 초기값과 재귀 횟수를 고정한다.
- 실적 제외: 보고일 포함 앞으로 5개 정규장 거래일의 마지막 날짜까지 다음 확정 발표일이 있으면 제외한다. 중간 휴일·주말에 발표하는 경우도 날짜 구간에 포함한다. 장전·장후 시각은 제외 여부에 영향을 주지 않는다. 다음 확정 발표일이 없거나 예상만 있으면 보류한다.
- 순위: 이 티켓은 한 종목이므로 선정된 경우만 1위다. 후속 전체 탐색에서는 거래량 증가 배율 내림차순, 평균 거래대금 내림차순, 티커 오름차순으로 정렬한다.

계산에는 `Decimal` 28자리 정밀도를 사용한다. 중간 값은 표시용으로 반올림하지 않는다. 보고서의 가격 표시는 소수 둘째 자리에서 반올림하며 원래 계산값과 산식은 기록에 남긴다.

선정된 종목만 진입 검토 구간 `[T 종가, T 종가 + 0.5ATR]`, 손실 제한 기준 `돌파 기준선 − ATR`, 예시 `1R = T 종가 − 손실 제한 기준`, 예시 이익 실현 기준 `T 종가 + 2R`을 표시한다. ATR·손실 제한 기준·1R이 양수가 아니면 보류한다. 진입 계획은 보고일 정규장 하루에만 유효하며 실제 진입가가 달라지면 다시 계산한다. 실제 체결이나 최대 손실을 보장하지 않는다.

필수 자료의 미검증은 `held`/평가 불가, 검증된 자료의 조건 탈락은 `excluded`/조건 충족 후보 없음, 모든 조건 통과는 `selected`로 기록한다. 필수 자료 누락을 확인한 경우 조건 탈락보다 보류가 우선한다. 실적 날짜가 확정되었더라도 시세가 미검증이면 후보가 될 수 없다.

## 기록과 검증 경계

단건 실행은 새 디렉터리에 `record.json`과 `report.md`를 작성한다. 기록에는 형식·규칙 버전, 코드 해시, 규칙 본문, 실제 자료/검증 사례 구분, 요청 URL과 확인 시각, 수집한 공개 응답, 수집 실패 분류, 정규화 자료와 판정·계산 결과를 보존한다. 인증 헤더·환경변수·오류 응답 본문은 기록하지 않는다. 기존 실행 디렉터리는 덮어쓰지 않는다.

재현은 네트워크 없이 보존된 공개 응답을 다시 정규화·계산하여 결과가 일치하는지 확인한다. 코드·규칙 버전이 다르거나 입력 무결성이 달라지면 일치를 주장하지 않는다. 합성 응답을 쓰는 검증은 최종 보고서와 기록을 읽는 단건 실행 경계에서 수행하고 실제 연동 증거와 구분한다. 조건 경계, 가격 계획, 잘못된 시세, 실적 미확인·예상·제외 기간·장전·장후, 휴장일, 재현 및 실패 결과를 확인한다.
