# 이슈 #232 검증 기록

2026-09-10 기준 로컬 단건 실행·보고서·재현 기능을 구현했다. 실제 시세 연동 검증은 미완료이므로 이슈 전체의 완료를 주장하지 않는다. 키 입력용 틀과 실행 방법은 [실행 안내](single-run.md), 계산 전에 고정한 규칙은 [데이터·계산 계약](single-run-contract.md)에 있다.

## 실제 자료

최종 코드로 인증정보를 환경에서 제외하고 `python3 single_run.py run --output runs/issue232-public-final`을 실행했다. 기록 기준 시각은 `2026-09-10T07:41:05.041522+00:00`이다. 공식 뉴스룸과 연결된 기업 IR 11개 페이지를 자동 수집했다. 토스·KIS 수집 4단계는 인증정보 미설정으로 기록되었으며 실제 인증 요청은 하지 않았다.

자동 수집한 [Micron 실적 발표 공지](https://investors.micron.com/news/press-release/2026/Micron-Technology-to-Report-Fiscal-Fourth-Quarter-Results-on-September-30-2026/default.aspx)에서 다음 확정 발표일 `2026-09-30`, 공지 발행 시각 `2026-08-26T15:01:00+00:00`을 추출했다. 각 페이지의 실제 확인 시각과 공개 응답은 로컬 기록에 보존했다. 사람이 날짜를 입력하거나 검색 결과를 보고서 입력으로 옮기지 않았다.

최종 보고서는 `held`/평가 불가다. 종목 정보·거래일·원주가·수정주가 인증 응답이 없고 KIS 일봉의 정규장 전용 집계 여부도 미검증이다. 이 결과로 실제 시세 연동이나 실제 후보 평가 완료를 주장하지 않는다. 코드에는 실제 자료를 임의로 검증 완료로 바꾸는 실행 옵션이 없다.

- 로컬 보고서: `runs/issue232-public-final/report.md`
- 로컬 재현 기록: `runs/issue232-public-final/record.json`
- 기록 내 무결성 SHA-256: `81f0fdc57294ff287fc003817b2d5dfd82c98eebc8a43df8329e6705c0d76172`
- 실행 코드 SHA-256: `5c7c0977d5e4d17e17d4fea6ab4ff42fe9b102f82368527fd070285943f82f53`

`python3 single_run.py replay runs/issue232-public-final`은 네트워크 없이 수집 응답을 다시 처리하고 원래의 보류 결과·보고서 일치를 확인해 종료 코드 `0`을 반환했다. 원본 실행의 종료 코드는 보류를 뜻하는 `2`다. `runs/`는 Git에서 제외되므로 다른 체크아웃에서 이 기록을 사용하려면 해당 디렉터리와 같은 코드 버전이 필요하다.

## 실행 가능한 검증

Python `3.14.7`에서 `python3 -m unittest discover -v`의 테스트 18개가 통과했다. 단건 실행 경계에서 다음 동작을 확인했다.

- 규모·유동성·돌파·거래량·이동평균의 초과·이상 경계와 정상 후보의 가격 계획
- 실적 미발견·예상·잠정·연기, 보고 당일·다섯째 거래일·중간 주말·장전·장후 제외와 여섯째 거래일 허용
- 별도 후속 연기 공지가 기존 발표일의 확정 판단을 무효화하는 동작
- 0·음수·비유한 수치·OHLC 역전·거래대금 단위 불일치, 누락·중복·미래·오래된 일봉 보류
- 원주가·수정주가 불일치, 지원하지 않는 종목 유형, 휴장·잘못된 보고 시각
- 실제 세션 미검증 자료에서 후보·가격 계획 차단, 오프라인 재현, 기록 변경 탐지, 기존 출력 보존
- 키만 입력한 CLI에서 명시적 옵션이 있을 때만 토큰 요청, 토큰·키가 보고서·기록·출력에 포함되지 않는 동작

최초 정상 사례는 구현 파일이 없을 때 실패했고 구현 후 통과했다. 인증 파일·명시적 토큰 발급 사례는 CLI 옵션이 없을 때 실패했고 구현 후 통과했다. 별도 연기 공지 사례는 수정 전 `selected != held`로 실패했고 수정 후 통과했다.

`python3 check_negative_controls.py`는 같은 Python·명령·입력으로 임시 코드 복사본을 검사한다. 아래 12개 오류 모두 정상 코드 종료 `0`, 오류 코드 종료 `1`, 단언 실패 확인 결과를 얻었다.

`py_compile` 문법 검사와 `git diff --check`도 통과했다. 정적 타입 검사는 설치된 검사기가 없어 실행하지 않았다. 문법 검사를 타입 검사로 간주하지 않으며, 별도 패키지는 설치하지 않았다.

## Spec

별도 리뷰 에이전트가 이슈 #232의 요구사항과 전체 구현 차이를 검토했다. 이후 실적 일정 변경 공지를 놓치는 결함 1건을 제시했고, 실패 재현·수정·재검토를 마쳤다. 재검토에서 추가 코드 결함은 없었다. 실제 인증 시세 검증은 외부 입력을 기다리는 미완료 항목으로 남았다.

## 남은 확인

사용자가 로컬 비공개 파일에 인증정보를 입력한 뒤 실제 종목·시세 읽기 전용 조회를 확인해야 한다. 새 토큰 발급은 토스 기존 토큰의 무효화와 KIS 알림 가능성이 있으므로 명시적 실행 승인이 필요하다. 이후 실제 단위·거래일·세션·수정주가 특성을 확인하고 수집 계약과 보류 조건을 갱신해야 한다. 합성 자료의 후보 통과를 실제 응답 확인의 대체물로 사용하지 않는다.

AI·텔레그램·전체 탐색·예약 실행은 이 티켓의 후속 범위다. 사용자가 작업 전에 수정하던 `README.md`, `docs/requirements.md`, `docs/first-milestone.md`는 작업 전후 SHA-256 비교로 바이트 일치를 확인했다.
