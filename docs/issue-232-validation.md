## 2026-09-11 인증 조회와 실제 응답 검증

사용자의 승인 후 기존 키로 토스·KIS 토큰을 발급하고 공개 종목·시세 API를 조회했다. 토큰은 실행 프로세스 메모리에서만 사용했다. 수집 파일에서 실제 키·토큰 값의 포함 여부를 검사했고 검출되지 않았다. 계좌·보유·주문 조회는 수행하지 않았다.

첫 실행 `runs/issue232-authenticated-20260911`에서는 거래일 조회가 HTTP 429로 중단되었다. [토스 공식 호출 한도](https://openapi.tossinvest.com/openapi-docs/overview.md)의 MARKET_INFO 초당 3회에 맞춰 단일 실행의 인증 GET 간격을 0.15초에서 0.35초로 늘렸다. 수정 후 실행 `runs/issue232-authenticated-paced-20260911`은 기준 시각 `2026-09-11T04:51:16.400086+00:00`에 시작해 70개 응답을 오류 없이 수집했다. 두 실행에서 각각 토큰을 발급했으며 자동 재발급·재시도는 하지 않았다.

KIS 상세 시세의 시가총액 `1,103,877,079,900 USD`는 해당 응답의 발행주식수 `1,129,390,000` × 종가 `977.41`과 일치했다. 토스 발행주식수와는 3,151주 차이가 있어 서로 같은 기준의 값으로 간주하지 않았다. 이 추가 조회는 제공값 확인용이며, 실행 계약의 시가총액 산식을 바꾸지 않았다.

자동 수집 응답을 오프라인 비교한 결과 다음 문제가 남았다.

- 2026-07-08 KIS 원주가의 저가·고가는 `900.41~959.00 USD`인데 거래대금 `41,503,556,202` ÷ 거래량 `42,978,962`는 약 `965.67144`다. 같은 세션·단위의 거래라는 계약에 맞지 않는다. 차이의 원인을 시간외 거래나 제공자 오류로 단정하지 않았으며 거래대금을 종가 × 거래량으로 대체하지 않았다.
- 2026-07-01과 07-02의 KIS 원주가·수정주가 OHLC가 다르다. 07-02 종가는 각각 `975.56`, `975.4098`이다. 기업행사 종류와 가격·거래량·거래대금 조정 관계는 확인되지 않았다.
- 토스와 KIS의 원주가 OHLCV는 평가 구간 50개 모두 일치했고, 수정주가 OHLCV는 48개가 일치했다. 나머지 2개는 위 날짜의 가격 필드가 다르다. 제공자 간 일치만으로 정규장 전용 집계나 전체 시장의 거래대금 수집을 입증하지 않는다.
- [KIS 일봉 공식 설명](https://apiportal.koreainvestment.com/api/apis/public/detail?accessUrl=%2Fuapi%2Foverseas-price%2Fv1%2Fquotations%2Fdailyprice)은 무료 Nasdaq TotalView의 제공 범위와 유료 시세와의 차이를 안내한다. 조회한 설명으로 정규장 전용 집계 여부를 확인하지 못했다.

기존 세션 미검증 보류가 시세 수치 오류를 가리는 조기 반환을 수정했다. 원본 기록을 보존한 채 저장된 70개 응답을 수정 코드로 다시 처리했으며, 새 조회나 수동 시세 입력은 하지 않았다. 파생 기록은 원본 `as_of`·요청별 `checked_at`·응답을 유지하고 원본 무결성 해시와 재처리 시각을 추가했다. 최종 사유는 `kis_regular_session_unverified`, `turnover_unit_or_session_mismatch`이며 가격 계획은 없다. 검증은 첫 수치 오류에서 멈추므로 수정주가 차이는 위 별도 비교 기록에 남았다.

## 실행 가능한 검증

2026-09-11 Python `3.14.7`에서 `python3 -m unittest discover -v`의 테스트 20개가 통과했다. 단건 실행 경계에서 다음 동작을 확인했다.

- 규모·유동성·돌파·거래량·이동평균의 초과·이상 경계와 정상 후보의 가격 계획
- 실적 미발견·예상·잠정·연기, 보고 당일·다섯째 거래일·중간 주말·장전·장후 제외와 여섯째 거래일 허용
- 별도 후속 연기 공지가 기존 발표일의 확정 판단을 무효화하는 동작
- 0·음수·비유한 수치·OHLC 역전·거래대금 단위 불일치, 누락·중복·미래·오래된 일봉 보류
- 원주가·수정주가 불일치, 지원하지 않는 종목 유형, 휴장·잘못된 보고 시각
- 실제 세션 미검증 자료에서 후보·가격 계획 차단, 오프라인 재현, 기록 변경 탐지, 기존 출력 보존
- 키만 입력한 CLI에서 명시적 옵션이 있을 때만 토큰 요청, 토큰·키가 보고서·기록·출력에 포함되지 않는 동작

## Standards

## Spec

## 남은 확인

인증 연결과 실제 종목·거래일·시세 자동 수집은 확인했다. 남은 항목은 KIS 일봉의 세션·거래대금 불일치에 대한 제공자 근거 확인과 기업행사 조정 관계 검증이다. 이를 확인하거나 검증 가능한 다른 공개 수집 경로를 확보한 뒤 수집 계약과 보류 조건을 갱신해야 한다. 유료 구독·범위 변경은 이번 작업에 포함하지 않았다. 합성 자료의 후보 통과를 실제 응답 확인의 대체물로 사용하지 않는다.

AI·텔레그램·전체 탐색·예약 실행은 이 티켓의 후속 범위다. 사용자가 작업 전에 수정하던 `README.md`, `docs/requirements.md`, `docs/first-milestone.md`는 작업 전후 SHA-256 비교로 바이트 일치를 확인했다.
