# Triage Labels

스킬의 표준 역할을 다음 GitHub 라벨에 대응시킨다.

| 표준 역할 | 실제 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 유지관리자의 검토가 필요하다. |
| `needs-info` | `needs-info` | 보고자의 추가 정보를 기다린다. |
| `ready-for-agent` | `ready-for-agent` | 명세가 준비되어 에이전트가 작업할 수 있다. |
| `ready-for-human` | `ready-for-human` | 사람이 구현해야 한다. |
| `wontfix` | `wontfix` | 처리하지 않기로 결정했다. |

스킬이 표준 역할을 언급하면 이 표의 실제 라벨을 사용한다.
