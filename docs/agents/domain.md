# Domain Docs

이 저장소는 단일 도메인 구조를 사용한다. 용어는 루트의 `CONTEXT.md`, 설계 결정은 `docs/adr/`에서 관리한다.

## 탐색 전에 읽을 문서

- 루트의 `CONTEXT.md`를 읽는다.
- 작업 대상과 관련된 `docs/adr/`의 결정을 읽는다.
- 해당 문서가 없으면 조용히 진행한다. 용어나 결정이 확정될 때 `domain-modeling`으로 문서를 만든다.

## 용어 사용

이슈, 설계 제안, 가설, 테스트에서 도메인 개념을 표현할 때 `CONTEXT.md`의 용어를 사용한다.

필요한 개념이 용어집에 없으면 기존 용어로 표현할 수 있는지 확인한다. 실제 용어 공백이면 `domain-modeling`에서 다룰 항목으로 기록한다.

## 설계 결정과의 충돌

제안이 기존 ADR과 충돌하면 해당 ADR과 재검토 이유를 명시한다.
