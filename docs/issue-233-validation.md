# 이슈 #233 검증 기록

## 2026-09-24 목록·IR·거래대금 경로 후속 구현

남은 네 항목을 병행해 진행했다. 목록 충돌은 종목별 일반·유형별 원본 행과 사유를 기록·보고서에 보존한다. 공통 IR 수집기는 상대 링크·다음 페이지·중첩 JSON-LD·발행 메타데이터·Q4 피드를 지원하고, 출처 미등록·형식 미지원·실패·불완전·조회 완료 후 근거 미확보를 구분한다. 기본 출처는 11개 기업·12개 티커이며, 날짜를 직접 입력하는 경로는 없다. 한 종목 규칙 v4·전체 규칙 v3로 구분한다.

전체 64개 테스트와 49개 오류 주입 대조가 통과했다. 49개 대조는 같은 격리 복사본 절차에서 정상 구현의 통과와 변형 구현의 단언 실패를 확인했다. IR·Alpaca 자체 검사, Python 구문 검사와 `git diff --check`도 통과했다. 정적 타입 검사기는 설치되어 있지 않아 생략했다. 합성 6종목은 선정 5·제외 1이며 후보는 DDD·BBB·CCC다. `runs/issue233-ir-synthetic-20260924/`에 소스·계약·보고서·기록을 보존하고 네트워크 없이 재현했다. 이 결과는 실제 시장 평가가 아니다.

시작 커밋 `cf6e0b5`부터 현재 변경 전체를 규약·요구사항 두 축으로 검토했다. 제목 때문에 본문을 생략하던 처리, 인접한 잠정 문구 누락, 콜 날짜 혼동, 일반 제목의 변경 공지 누락, JSON-LD와 HTML 본문 충돌, 회계기간 종료일 혼동을 재현했다. 실행·보고서·기록·재현 경계에서 잘못 선정되는 실패를 먼저 확인하고 같은 입력이 보류되는 수정 후 결과를 확인했다. 회계기간 날짜의 일반·서수·요일 표기도 동일한 정규화와 추출 패턴을 사용한다. 두 축 재검토에서 제기한 구현 결함의 해소를 확인했다. 네 개의 원래 완료 조건은 아래 이유로 여전히 미완료다.

## 2026-09-24 검증된 탈락의 조기 제외

종목 식별과 기존 50거래일 가격·거래량·기업행사 검증을 유지한 채 규모·돌파 등의 조건을 먼저 판정하도록 변경했다. 검증된 탈락이면 실적·거래대금 수집을 생략하고, 가격 조건을 통과한 경우 실적을 확인한 뒤 필요한 거래대금만 수집한다. 두 실행 경로가 공통 판정과 후속 수집을 사용한다. 제외 근거와 `inputs.skipped`의 항목·사유를 보고서와 기록에서 구분한다. 가격 불일치·분할·식별 오류·장전 수집 범위 이탈은 탈락 근거가 아니다.

실적 출처가 없는 저시가총액 종목의 제외와 미조회 기록을 실행·보고서·record.json·오프라인 재현 경계에서 검증했다. 새 동작은 수정 전 실패·수정 후 통과를 확인했다. 전체 52개 테스트, 43개 오류 주입 대조, Alpaca·IR 자체 검사, Python 구문 검사와 `git diff --check`가 통과했다. 오류 주입 대조는 격리한 복사본에서 같은 테스트를 정상 구현과 변형 구현에 실행해 정상 통과·변형 단언 실패를 확인한다. 정적 타입 검사 도구는 설치되어 있지 않아 해당 검사는 생략했다.

합성 6종목 실행은 선정 5·제외 1이고 상위 3개는 DDD·CCC·BBB다. 저시가총액 IBM의 실적·거래대금 조회를 생략했으며 보고서와 기록을 네트워크 없이 재현했다. 이는 실제 시장 평가가 아니다. 로컬 기록은 `runs/issue233-early-exclusion-20260924/`에 있으며 Git에서 제외된다. 규칙 변경 전 기록은 당시 코드로만 재현하고 현재 결과로 덮어쓰지 않는다.

저장된 Alpaca 정상일 169페이지도 인증 조회 없이 재현해 수집 완료·검증 보류를 확인했다. 이 결과는 정확 거래대금 검증이나 새 전체 실행의 증거가 아니다. 상세 범위는 [데이터 경로 검증](issue-233-data-probe.md)에 있다.

시작 커밋 `cf6e0b5` 이후 변경 전체와 미추적 실험 코드를 규약·요구사항 두 축에서 검토했다. 규약 리뷰에서 공유 안내의 개인 인증 파일 경로를 일반 자리표시자로 수정했고 재검토에서 해소를 확인했다. 요구사항 리뷰에서 이전 수집 순서를 설명하던 실행 안내를 수정했고 재검토에서 해소를 확인했다. 새 조기 제외 로직의 확정된 실행 결함은 보고되지 않았다. 전체 목록 정합성·MU 외 IR 수집·정확 거래대금과 동률 정렬·실제 전체 실행은 여전히 미완료다. 실제 전체 조회, 추가 인증정보 사용과 토큰 발급은 이번 변경에서 수행하지 않았다.

## 2026-09-14 검증 기록

2026-09-14 전체 목록 수집·종목별 보류·최대 3개 기본 보고서·오프라인 재현을 검증했다. 실제 실행은 목록에서 확인한 4,842종목 중 MU 1종목을 조건 미충족으로 제외하고 실적 출처가 없는 4,841종목을 보류했다. Nasdaq 목록 불일치, MU 외 실적 출처, 정확한 평균 거래대금에 따른 동률 정렬이 남아 있으므로 이슈 #233은 미완료다.

## 확인한 동작

- 전체 테스트 40개가 통과했다. 기존 한 종목 테스트 28개와 전체 실행 경계 테스트 12개다.
- `check_negative_controls.py`의 39개 오류 주입 검증이 모두 통과했다. 각 검증은 격리된 임시 디렉터리에서 동일한 테스트를 정상 구현과 변형 구현에 실행했다. 정상 구현은 종료 코드 0, 변형 구현은 종료 코드 1과 단언 실패를 확인했다.

시작 커밋 `cf6e0b5` 대비 변경을 규약 준수와 이슈 요구사항으로 나누어 별도 에이전트가 검토했다. 두 리뷰에서 일반 목록 한 행의 `securityType` 누락이 전체 실행을 중단시키는 결함을 확인했다. 같은 실행 경계의 테스트에서 기존 `KeyError`를 재현하고 필수 필드 검사를 오류 처리 경계 안으로 옮겼다. 같은 테스트의 통과와 필드 검사를 제거한 변형 구현의 실패를 확인했으며 재검토에서 해결됐다는 판정을 받았다. 최종 규약 검토의 미해결 지적은 없고, 요구사항 검토에는 아래 두 항목이 남았다.

## 실제 수집과 남은 항목

처음에는 기존 액세스 토큰이 없어 인증 GET 전에 멈췄다. 이후 사용자 승인으로 토스·KIS 토큰을 각각 한 번 발급했다. 첫 사전 조회에서 4,842종목과 Nasdaq의 일반 목록에만 있는 PSNYW를 확인했다. 이어진 시세 수집은 실적 출처가 없어 이미 보류가 확정된 종목까지 조회했다. 마지막 진행 출력은 요청 700회·경과 321.6초였고, 사용자 승인으로 이 실행을 중단했다. 이 중단 실행은 최종 보고서·재현 기록을 만들지 못했으며, 보존된 사전 조회 기록과 진행 출력만으로 전체 시세 수집을 입증하지 않는다.

실적 미확인 종목의 시세 조회를 생략하도록 수정한 뒤, 추가 승인으로 두 서비스의 토큰을 각각 한 번 더 발급했다. 토큰은 두 실행 모두 프로세스 메모리에만 보관했다. 수정 실행의 기록에서 사용한 인증 값이 검출되지 않는 것을 확인한 뒤 프로세스를 종료했다.
