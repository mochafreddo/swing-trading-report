## 실제 수집과 남은 항목

승인받은 기존 인증정보로 토스·KIS의 조회를 시도했으나 두 서비스 모두 `credentials_not_configured`로 인증 GET 전에 멈췄다. 사용 가능한 액세스 토큰이 없어 토큰 발급 승인을 요청한 상태다. 토큰을 발급하거나 저장하지 않았으며 실제 전체 목록·호출 소요 시간·전체 평가를 확인하지 못했다.

1. 기존 KIS 정규장 분봉의 거래대금 하한은 유동성 통과만 확인한다. 정확한 평균 거래대금에 따른 동률 정렬과 두 값이 같은 경우의 티커 정렬은 실제 계산 경로에 구현되지 않았다. 문서에 고정한 기준과 미확정 보류 처리를 원래 완료 조건의 충족으로 간주하지 않는다.
2. 실제 전체 대상 구성과 자동 평가가 미검증이다. 기본 기업 IR 경로는 MU만 등록되어 있으며 나머지는 출처 미등록으로 보류한다. 실제 전체 실행에서 이 범위와 API 미지원·누락·단위·세션 오류를 구분해 확인해야 한다.
