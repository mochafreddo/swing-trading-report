# 검증된 조건 탈락으로 제외를 확정한다

2026-09-14 #233 후속 설계에서, 종목 식별과 해당 조건의 판정 근거를 검증했고 선정 조건 하나 이상을 충족하지 못하면 제외를 확정하고 나머지 자료 수집을 생략하기로 했다. 예를 들어 검증된 시가총액이 100억 USD 미만이면 실적 발표일을 조회하지 않아도 규모 조건으로 제외한다. 탈락 근거가 없고 필수 자료가 미확인인 종목은 계속 보류하며, 후보 선정에는 모든 필수 조건의 검증을 요구한다.

기존의 필수 자료 미확인 우선 정책은 다른 조건에서 이미 탈락한 종목까지 실적·거래대금 자료를 요구했다. 새 정책은 독립적으로 입증한 탈락을 활용해 불필요한 수집을 줄이는 대신, 제외 근거와 확인하지 않은 조건을 기록과 보고서에서 구분해야 한다. 종목 식별이나 해당 판정의 입력이 미검증인 경우에는 이를 탈락 근거로 사용할 수 없다. 거래대금 하한이 문턱 미만인 사실도 유동성 탈락의 근거가 아니다.

첫 구현은 기존 50거래일 가격 자료, KIS·Yahoo 가격 대조와 기업행사 확인을 유지한다. 검증된 규모·돌파 등에서 탈락하면 이후 실적·거래대금 수집을 생략한다. 판정별로 필요한 가격 검증까지 축소하는 변경은 실제 수집 시간을 측정한 뒤 별도로 검토한다.

2026-09-24에 공통 평가 로직과 두 수집 경로에 반영했다. [한 종목 평가 계약](../single-run-contract.md)은 규칙 v3, [전체 종목군 평가 계약](../universe-run-contract.md)은 규칙 v2다. 가격·식별 검증이 실패한 종목은 보류하고 후속 수집을 생략한다. 보고서와 기록은 검증된 제외 근거와 미조회 항목을 구분한다. 기존 실행 기록을 새 규칙으로 계산한 결과를 과거 실행의 재현으로 취급하지 않는다. 실제 전체 대상 재실행과 소요 시간 측정은 아직 남아 있다.
