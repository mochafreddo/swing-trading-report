# AI 입력을 공개 자료와 후보 선정 결과로 제한한다

첫 버전에서 OpenAI API에는 공개 시세·기업 자료와 후보 선정 결과만 전달한다. 개인 계좌의 실제 거래 기록은 AI 입력 범위에 포함하지 않는다.

실제 거래 내역을 함께 전달하면 개인별 복기에 활용할 수 있지만, 계좌 자료가 외부에서 처리되는 범위도 넓어진다. 첫 버전의 목적은 공개 자료를 바탕으로 매수 후보와 매매 계획을 설명하며 스윙 트레이딩 학습을 돕는 것이다. 사용자는 이 단계에서 공개 자료만 전달하고 개인별 AI 복기는 별도 범위로 정하기로 했다.

후속 단계의 토스증권 거래 기록 자동 수집은 이 결정의 AI 입력 범위를 확대하지 않는다. 개인별 AI 복기를 추가할 때 입력 자료와 처리 범위를 다시 정한다.
