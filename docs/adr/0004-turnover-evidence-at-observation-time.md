# 거래대금은 확인 시점의 검증된 값으로 사용한다

2026-10-10 #233 설계 인터뷰에서, 정확한 정규장 거래대금은 보고서마다 자료 확인 시점과 사용한 응답을 고정해 판단하기로 했다. 해당 시점까지의 정정·지연 보고가 반영됐다는 공급자 근거를 요구한다. 이후 정정은 별도 기록하고 원래 보고서의 재현 결과는 유지한다.

공급자의 집계 계약 확인과 독립 대조를 모두 정확성 검증의 조건으로 삼는다. 동일한 세션·체결 조건·정정 기준의 기준값과 비교하며, 차이가 있으면 원인을 설명하기 전까지 보류한다. 거래량 일치만으로 거래대금까지 검증됐다고 인정하지 않는다. 집계 계약이 다른 공급자끼리 합계가 다르다는 사실만으로 오류를 단정하지 않는다.

독립 대조에는 임의의 퍼센트 오차를 허용하지 않는다. 문서로 확인한 반올림·절삭 규칙으로 차이를 설명할 수 있을 때만 허용하며, 이 경우에도 정확한 값이 일치했다고 표현하지 않는다. 가능한 금액 범위에 따라 유동성 문턱 통과나 순위가 달라질 수 있으면 해당 판정은 보류한다.

기존 거래대금 하한의 충분조건은 유지한다. 최근 20거래일 평균의 검증된 하한이 5,000만 USD 이상이면 유동성 통과를 입증한다. 하한이 문턱 미만이면 정확한 값 확보 전까지 보류하고, 거래량 증가 배율이 같은 종목은 정확한 최근 20거래일 평균 거래대금으로 정렬한다. 정확한 값은 거래대금으로 판정해야 할 때 수집하며, 하한을 정확한 값으로 표시하지 않는다.

나중에 정정된 최신 값으로 원래 보고서를 덮어쓰면 당시 판단의 근거를 잃는다. 반대로 원문을 보존한 것만으로 값의 정확성이 입증되지는 않으므로 시점 고정과 정확성 검증을 함께 요구한다. 이 결정은 설계 기준이며, 공급자 계약이나 독립 기준값을 확보했다는 뜻이 아니다. 자료 경로의 검증 상태는 [데이터 경로 검증](../issue-233-data-probe.md)에 기록한다.
