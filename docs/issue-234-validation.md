# 자동 수집 근거와 AI 설명 검증

2026-10-10에 [#234](https://github.com/mochafreddo/swing-trading-report/issues/234)의 한 종목 뉴스·공시 수집과 AI 설명을 단건 실행에 연결했다. [설명 계약](report-explanation-contract.md)과 [실행 안내](single-run.md#뉴스와-ai-학습-설명)에 수집 범위·키 사용·비용 기록·검토 한계를 기록했다.

## 구현과 합성 검증

Python 3.14.8의 단건 실행 전체 경계에서 다음을 확인했다. API 응답을 합성 자료로 대체한 결과이며 실제 후보 통과나 시장 위험 부재를 입증하지 않는다.

- 뉴스와 SEC 접수 시각에 대해 직전 7일의 시작은 포함하고 기준 시각은 제외한다. 기준 시각 이후 자료와 잘못된 기업 식별은 사용하지 않는다. 실적 일정은 뉴스 기간 밖에서도 확인한다.
- 자료 없음·부분 수집 실패·잘못된 게시일에서도 검증된 후보와 계산값을 유지하며 보고서와 재현 기록을 저장한다.
- OpenAI에는 공개 근거와 코드 평가 결과의 허용 필드만 전달한다. 합성 계좌·실제 거래 필드는 전달되지 않는다. 실제 계좌·주문 API는 호출하지 않는다.
- AI가 다른 가격을 쓰거나 근거 없는 사실을 주장해도 확정 계산값은 바뀌지 않는다. 없는 출처·다른 시각·일치하지 않는 인용은 확인 불가로 표시한다. 올바른 인용을 붙여도 AI 서술의 사실관계는 별도의 `unconfirmed` 상태다.
- AI 정상 생성, 통신 장애, 월 예산 소진, 손상된 비용 기록을 확인한다. 장애는 기본 보고서를 유지하고 자동 재시도하지 않는다. 예산 소진·원장 오류는 API를 호출하지 않는다.
- 공유 인증 파일 템플릿의 OpenAI 키를 CLI에서 사용할 수 있으며 키는 결과에 포함되지 않는다. 오프라인 재현에는 네트워크나 키가 필요하지 않다.

최종 전체 `mise run test`에서 131개 테스트와 두 프로브 자체 검증이 통과했다. Ruff 린트·포맷, actionlint, Python 구문 검사, Git diff 검사도 통과했다. 정적 타입 검사기는 설치되어 있지 않아 타입 검사를 생략했으며 구문 검사로 대체했다고 주장하지 않는다.

## 오류 주입 검증

기존 `mise run negative-controls`의 121개 오류 모두 정상 구현 종료 코드 0, 오류 구현 종료 코드 1과 단언 실패를 확인했다. 새 설명 모듈과 계약도 임시 검증 사본에 포함하고, 기존 재현 시각 변경 오류의 위치를 현재 코드에 맞춰 지정했다.

새 범위에는 dotfiles의 `mutation-probe.py`를 오류마다 한 번씩 호출했다. 인증 파일과 실행 자료를 제외한 소스·문서 사본에서 같은 Python과 같은 단건 테스트를 정상·변형 구현에 실행했다. 아래 9개 모두 정상 구현 종료 코드 0, 오류 구현 종료 코드 1을 확인했으며 변형 대상 소스는 원래 상태를 유지했다.

| 보호 대상 | 주입한 오류 | 검증 테스트 |
| --- | --- | --- |
| 뉴스 기간 경계 | 기준 시각의 자료까지 포함 | `test_news_window_is_closed_at_start_and_open_at_as_of` |
| 자료 없음과 선정 분리 | 뉴스가 없으면 선정 결과를 보류로 변경 | `test_empty_and_failed_news_keep_verified_candidate_and_basic_report` |
| 공개 입력 범위 | 허용 목록 밖의 전체 입력 객체를 전달 | `test_ai_only_receives_public_evidence_and_cannot_change_calculations` |
| 계산값 보존 | 저장 직전 진입가를 999로 변경 | 같은 공개 입력·계산 테스트 |
| AI 장애 처리 | 통신 오류의 기본 보고서 처리를 제거 | `test_budget_exhaustion_and_ai_failure_produce_basic_report_without_retry` |
| 월 예산 | 호출 전 예산 검사를 제거 | 같은 장애·예산 테스트 |

새 회귀 검사는 `python -B -m unittest test_report_explanation -v`로 실행한다. 문장의 의미를 검증하는 AI 판별기나 보고서 읽기 시간 측정은 수행하지 않았다. 약 5분은 목표이며 실제 독자의 읽기 시간으로 측정한 값이 아니다.

## 실제 연동

최종 실제 실행 기준 시각은 `2026-10-10T11:32:12.526008+00:00`이며 로컬 자료는 `runs/issue234-verified-20261010/`에 보존했다. 현재 코드를 기준으로 이 실행의 뉴스 정규화·AI 입력 해시·인용 검토·토큰 비용·보고서 오프라인 재현이 통과했다. 사용한 인증정보가 기록과 보고서에 포함되지 않았음을 값 미출력 검사로 확인했다.

- 공식 기업 뉴스 1건을 자동 수집했다. 게시 시각은 `2026-10-09T16:21:00+00:00`이며 지정된 조사 기간 안에 있다. SEC 요청은 실패해 `sec_unavailable`과 부분 조사 상태로 기록했다. SEC 본문과 위험의 실제 수집 완료를 주장하지 않는다.
- OpenAI 실제 생성은 `generated`였다. 입력 1,116토큰, 캐시 입력 0토큰, 출력 478토큰을 응답에서 확인했다. 공개 단가로 계산한 비용은 0.0012112 USD이며 실제 청구서 금액과 구분한다. 유료 검색은 0회다.
- 선정 설명 1개·위험 2개·무효 상황 1개의 원문 인용이 일치했다. 다른 위험 1개와 학습 포인트의 인용은 일치하지 않아 보고서에서 확인 불가로 바꿨다. 인용 일치 여부와 별개로 모든 AI 서술의 사실관계는 확인 불가로 표시했다.
- 현재 시장 데이터 인증 토큰이 설정되어 있지 않아 종목·달력·시세 확인은 `credentials_not_configured`로 보류됐다. AI 생성 성공을 실제 시세 평가나 후보 선정 성공으로 표현하지 않는다. 새 토큰 발급은 수행하지 않았다. 실제 시세·가격 계획의 선행 검증은 [#232 검증 기록](issue-232-validation.md)에 별도로 있다.
- 최종 보고서는 3,217자였다. 전체 요청별 근거는 재현 기록에 보존하고 보고서에는 조사 범위와 대표 근거를 표시한다. 이전 후보의 경과를 만들지 않았다.

## 리뷰와 남은 범위

작업 시작 커밋 `3ffafb31d416e5fdd2d5dab5c6036f57c70155a8`을 기준으로 Standards·Spec를 독립적인 읽기 전용 `reviewer` 두 개에 검토 요청했다. 잘못된 게시일과 손상된 금액의 예외 누락, AI 사실관계와 인용 검증의 혼동, 보고서 문체를 보완하고 재검토에서 남은 조치 사항이 없음을 확인했다. 설정된 역할 선택은 세션 메타데이터로 확인했고, 실제 모델·추론 강도와 실행 권한 분리는 별도로 검증하지 않았다. 두 리뷰에는 `high`를 요청했다.

전체 종목군 탐색 #233, SEC 실제 수집 성공, 현재 시세 인증 복구, AI 문장의 의미 검증, 사용자 이해도·읽기 시간 측정, 텔레그램 전송은 이번 검증의 완료 증거에 포함하지 않는다. 후보 경과 갱신·예약 실행과 실제 거래 기록은 후속 범위다. 외부 이슈 상태나 원격 브랜치는 변경하지 않았다.
