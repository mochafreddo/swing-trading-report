# Reviews

상태: Archive

해결 완료된 리뷰 문서를 모아둡니다. 현재 기능 설명서가 아니라 검토 이력 아카이브이며, 최신 운영 기준은 [프로젝트 README](../../README.md)와 [`docs/README.md`](../README.md)를 우선합니다.

## Archive Handling

- 이 디렉터리의 리뷰 원문은 현재 source of truth가 아니므로, 오래된 파일 경로·라인 번호·당시 판단을 최신 계약처럼 인용하지 않습니다.
- 특정 finding을 다시 사용해야 할 때는 원문을 직접 고치지 말고 현재 코드, 테스트, README, `docs/ARCHITECTURE.md`, `docs/runbook.md`와 재검증한 뒤 현재 문서나 `TODOS.md`로 필요한 내용만 승격합니다.
- 이미 해결되었거나 후속 리뷰에서 재평가된 finding은 이력으로 보존합니다. archive 문서의 원본성 유지를 우선하고, 구조 이동이나 링크 보정은 active 문서 승격이 결정된 경우에만 수행합니다.
