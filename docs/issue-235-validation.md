# 텔레그램 단건 전송 검증 기록

2026-10-10 로컬 Mac에서 #235의 전송·기록·수신 확인 경계를 검증했다. 이 문서는 구현 및 검증 결과를 설명하며, 전체 종목군 보고서의 정시 전달 완료를 의미하지 않는다. 사용 절차와 응답 분류는 [텔레그램 전송 안내](telegram-delivery.md)에 있다.

## 로컬 검증

Python 3.14.8에서 `MISE_AUTO_INSTALL=0 mise run check`가 종료 코드 0으로 통과했다. 전체 unittest 116개, 두 프로브 자체 검증, 오류 주입 검사 121개, Ruff 린트·포맷 검사와 ShellCheck를 연동한 actionlint 검사를 실행했다. 새 도구는 설치하지 않았다. mypy·pyright가 설치되어 있지 않아 정적 타입 검사는 생략했다. 구문·린트 검사는 정적 타입 검사를 대신하지 않는다.

`test_telegram_delivery.py`의 8개 테스트는 합성 공개 응답으로 `single_run.run`을 실행해 보고서와 실행 기록을 생성한 다음 전송 경계를 확인한다. API 성공, 명시적 거절, 응답 불명확, 사용자 확인과 수동 재전송, 전송 도중 중단, 변경된 보고서·대상, 예정 분의 경계와 휴장일, 실제 HTTP 요청 형태와 비밀값 출력 방지를 검증한다. 이 API 응답과 시각은 모의 자료이며 실제 텔레그램 수신의 증거가 아니다.

불명확 응답에서 자동으로 한 번 더 전송하는 변형은 `mutation-probe.py`로 격리된 소스 복사본에서 검사했다. 정상 구현은 동일 테스트에서 종료 코드 0으로 통과했으며, 변형은 `AssertionError: 2 != 1`과 종료 코드 1로 실패했다. 원본 소스가 바뀌지 않았다는 프로브 검사도 통과했다. 이 검증과 사용자 미수신 확인을 생략하는 변형은 기존 오류 주입 검사에도 추가했다. 두 변형 모두 정상 종료 코드 0, 변형 종료 코드 1 및 단언 실패를 확인했다.

## 독립 리뷰

규약 준수와 이슈 충족 여부를 각각 읽기 전용 reviewer에게 검토하도록 요청했다. 세션 헤더 검사로 두 reviewer 역할 선택을 확인했다. 실제 모델·추론 강도·권한 적용은 확인하지 않았으며, 권한 격리에 의존한 작업은 수행하지 않았다.

규약 검토에서 HTTP 상태줄 예외의 전파, HTTP 5xx와 본문 오류 코드의 불일치, HTTP 3xx의 성공 오판정 가능성을 찾았다. 같은 CLI 전송 경계에 사례를 추가해 수정 전 실패를 확인했고, HTTPException 정제와 실제 HTTP 상태 검증으로 수정했다. 수정 후 테스트가 통과했으며 후속 독립 검토에서 미해결 지적이 없음을 확인했다. 이슈 충족 검토에서도 구현 결함은 보고되지 않았고, 실제 전송과 사용자 수신 확인이 별도 운영 검증임을 구분했다.

## 실제 개인 채팅 전송

`runs/telegram-235-preview-20261010`에 MU 한 종목의 합성 검증 보고서를 생성했다. 자료 기준일은 2026-09-10이며 현재 시장 자료로 해석하지 않는다. 저장된 공개 응답으로 재현 검증을 통과한 `report.md`를 미리보기 설명과 함께 실제 개인 채팅에 한 번 전송했다. 시세 공급자 API에 새로 접속한 검증은 아니다.

텔레그램 API는 메시지 ID 333과 발행 시각 `2026-10-10T10:31:08+00:00`을 반환했다. 한국시간으로 2026-10-10 19:31:08이다. `delivery.json`에는 `transport=telegram`, `status=sent`, `timing=preview`, `on_time=false`와 보고서·실행 기록 해시를 연결했다. `synthetic=true`는 보고서 자료가 합성이라는 뜻이며, 실제 API 전송 여부와 구분한다. 원격 오류 본문·토큰·chat ID 원문은 전송 기록에 저장하지 않는다.

사용자가 해당 개인 채팅의 설명과 `report.md` 파일을 받았다고 확인했다. 그 답변에 따라 같은 시도에 `receipt=received`와 확인 시각을 기록했다. API 성공만으로 사용자 수신을 추정하지 않았다. 실제 미수신·응답 불명확 상태를 일부러 발생시키거나 실제 재전송하지 않았으며, 해당 처리는 합성 테스트와 오류 주입 검사로 검증했다.

전체 보고서의 정시 전달과 내용 검토, 예약 실행·Mac 복구·지연 전달 자동화는 이 검증에 포함하지 않는다. 전체 보고서의 정시 전달과 내용 검토는 최종 통합 티켓에서 확인한다. GitHub CI는 이번 로컬 커밋의 검증으로 실행하지 않았다.
