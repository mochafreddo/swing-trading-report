# 전체 종목군 평가 계약

이 문서는 #233의 단건 실행·보고서·오프라인 재현 경계와 구현 전에 고정한 규칙을 설명한다. 기존 [한 종목 계산 계약](single-run-contract.md)의 가격 검증·계산·실적 정책을 적용한다.

NYSE·NASDAQ 각각의 토스 ACTIVE 보통주 전체 목록을 조회하고 STOCK·FOREIGN_STOCK 필터 목록의 합집합과 대조한다. 두 경로의 불일치·빈 목록·중복·다음 페이지 표시·요청 실패는 전체 범위 미확보다. 확인된 종목은 보존하고 상세 조회 누락은 해당 종목의 보류로 기록한다. 일반·유형별 목록의 차이는 종목별 원본 행과 `general_only`·`typed_only`·`row_conflict` 사유를 기록하며 보고서에도 표시한다. 공개 디렉터리만으로 토스 거래 가능 상태를 덮어쓰지 않는다. 공식 API는 페이지 없이 전체 반환을 명시하지만 독립적인 총건수는 제공하지 않는다. 일치하는 두 응답만으로 공급자 내부 누락의 부재까지 입증하지 않는다.

규칙 v4는 일반·유형별 목록이 충돌한 종목을 `stock_listing_conflict`로 보류하고 해당 종목의 가격·실적·거래대금 수집을 생략한다. 상세 응답이 일반 목록과 같더라도 유형별 목록과의 충돌이 해소됐다고 보지 않는다. 원본 목록·상세 응답은 보존하며 충돌 없는 종목의 판정은 유지한다.

상세 조회는 최대 200개씩 수행한다. 거래소와 심볼이 다른 응답을 변환으로 추정하지 않는다. NYSE는 KIS NYS, NASDAQ은 NAS로 조회하고 응답 식별자를 검증한다. Yahoo의 심볼 표기 차이는 점을 하이픈으로 바꾸어 조회하되 응답의 심볼·거래소·USD·정규장 날짜·가격을 검증한다. 미지원 심볼은 보류한다. 달력은 실행에서 공유하며 개장 이후에 수집된 종목은 보류한다.

실적 일정은 종목별로 등록한 기업 IR 목록 URL·기사 URL 접두사·정확한 기업명을 사용해 자동 수집한다. 등록 정보는 출처 설정이며 날짜 입력은 받지 않는다. 기본 등록은 `universe_run.DEFAULT_EARNINGS_SOURCES`가 기준이며, 등록 자체는 해당 기업의 일정 확인을 뜻하지 않는다. 기업명으로 시작하는 공지의 제목·본문에서 결과 발표일을 추출한다. 콜 날짜와 회계기간 종료일을 발표일로 대체하지 않으며, 제목·본문 또는 공지 간 미래 날짜가 충돌하면 보류한다. 일정 관련 예상·잠정 표현과 이후 취소·연기·변경 공지도 검사한다. 다른 종목에 MU 일정을 적용하지 않는다.

규칙 v3의 공통 IR 수집기는 상대 링크, HTML 다음 페이지, JSON-LD의 중첩 기사와 발행 메타데이터, Q4 공개 보도자료 피드를 지원한다. HTML의 `a`와 `link` 요소에 있는 `rel="next"`를 따르고, 기사 접두사 자체와 이미 조회한 목록 페이지는 기사에서 제외한다. HTML은 10페이지·100기사, Q4는 페이지당 5개·최대 200페이지이며 명시적인 빈 페이지까지 확인한다. 작은 페이지를 마지막으로 가정하지 않는다. 범위 초과·페이지 반복·지원하지 않는 형식·수집 실패는 확정 근거가 아니다. `collection_status`로 출처 미등록(`not_configured`), 형식 미지원(`unsupported`), 실패(`failed`), 범위 미확보(`incomplete`), 지원 경로 조회 완료(`complete`)를 구분한다. 조회 완료 후 다음 발표일을 찾지 못해도 보류한다. 시간대 없는 발행 정보는 날짜 정밀도로 기록하며 뉴욕 기준 조회 당일 또는 이후 공지는 발행 시각을 확인할 때까지 보류한다. 이 파서가 지원하지 않는 자유로운 공지 표현과 독자적인 동적 목록은 계속 보류한다.

규칙 v2는 종목 식별·달력·50거래일 가격·거래량·기업행사를 검증한 뒤 규모·돌파 등의 탈락을 먼저 판정한다. 검증된 탈락이 있으면 실적·거래대금 수집을 생략하며, 가격 조건을 통과한 종목만 실적을 조회한다. 실적이 제외 구간 안에 있거나 필수 근거가 미확인이면 거래대금 수집을 생략한다. 가격 불일치·분할·식별 불일치·장전 수집 범위 이탈을 탈락 근거로 사용하지 않는다. 제외 근거와 `inputs.skipped`의 미조회 항목·사유는 기록과 보고서에서 구분한다. 실적 미확인만으로 시세부터 생략하던 v1 실행은 당시 코드로만 재현한다.

순위는 거래량 증가 배율 내림차순, 정확한 최근 20거래일 평균 거래대금 내림차순, 티커 오름차순이다. 기존 KIS 분봉 금액 하한은 유동성 통과만 입증하며 두 번째 정렬 값이 아니다. 현재 수집 경로에서 첫 값이 같은 종목들은 순위 미확정으로 보류하고 다른 검증된 후보는 보존한다. 정확한 거래대금 출처 확보와 이 두 번째 정렬 기준의 실제 검증은 미완료 항목이다. 이를 전체 순위 검증 완료로 표시하지 않는다.

보고서는 최대 3개 후보의 선정 근거·가격 계획, 전체 목록 범위, 평가·제외·보류 건수, 보류 사유와 데이터 시각을 담는다. 전체 평가 불가와 검증된 범위의 후보 없음을 구분한다. 목록이 불완전해도 확인된 종목의 판정은 보존하되 전체 탐색 성공으로 표시하지 않는다. 모든 종목별 결과와 요청 URL·응답·확인 시각·오류·호출 수·소요 시간은 record.json에 보존한다. 인증정보는 저장하지 않는다. 재현은 저장 응답과 코드·계약·규칙·보고서 무결성을 확인하며 네트워크를 사용하지 않는다.

공식 근거는 [토스 종목 API](https://openapi.tossinvest.com/openapi-docs/latest/api-reference/Apis/StockInfoApi.md), [호출 한도](https://openapi.tossinvest.com/openapi-docs/overview.md), [KIS 일봉 예제](https://github.com/koreainvestment/open-trading-api/blob/main/examples_llm/overseas_stock/dailyprice/chk_dailyprice.py)다. 2026-09-14 조회한 토스 문서는 STOCK_ALL 초당 1회, STOCK 초당 5회, MARKET_INFO 초당 3회를 명시한다. 실행은 순차 수집하며 전체 목록 요청은 1.05초, 다른 인증 GET은 기존 0.35초 간격을 사용한다. 호출 실패는 자동 재시도하지 않는다.
