# swing-trading-report

미국 주식의 장전 매수 후보와 매매 계획을 제공하고 스윙 트레이딩 학습을 돕는 개인 도구다. 기존 구현을 정리하고 처음부터 재구축하며, Git 이력과 라이선스는 유지한다.

현재는 첫 버전의 요구사항과 첫 보고서 구현 계획을 정리하고 최종 확인하는 단계다. 운영 환경은 로컬 Mac이며, 보고서는 텔레그램으로 전달한다. AI 설명에는 OpenAI API를 사용하고 주문은 사용자가 직접 실행한다.
